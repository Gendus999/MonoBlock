# Inštalácia aplikácie (APK)

Tu nájdete hotový inštalačný balíček pripravený na stiahnutie.

### Súbory na stiahnutie:
- **`BlockBlast.apk`** — Inštalačný súbor aplikácie Block Blast pre Android zariadenia.

### Ako nainštalovať:
1. Stiahnite `BlockBlast.apk` priamo do svojho Android telefónu (alebo si stiahnite ZIP z GitHubu a preneste súbor do mobilu).
2. Kliknite na stiahnutý súbor `.apk`.
3. Ak vás systém vyzve, povoľte „Inštaláciu z neznámych zdrojov“ pre váš prehliadač alebo správcu súborov.
4. Potvrďte inštaláciu a spustite hru. Príjemnú zábavu!
